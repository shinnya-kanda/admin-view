# admin-view

配車管理画面

## 概要

GitHub上の `index.html` だけで動作する、配車管理デモ画面です。
バックエンドDBは使用せず、ブラウザの `localStorage` に一時保存します。

そのため、GitHub Pages または `index.html` をブラウザで開くだけで、以下の確認ができます。

- STOP入力タブから案件を作成
- 入力したSTOPがダッシュボード・STOP一覧・配車割当・営業所サマリーへ即時反映
- STOPの編集・削除・複製
- ドライバー割当の追加・完了・保留・未完了戻し・削除
- 簡易マスタの追加・削除
- 操作ログの確認

## 動作仕様

### 保存方式

保存先はブラウザの `localStorage` です。
同じブラウザ・同じURLで開く限り、リロードしてもデータは残ります。
ただし、別PC・別ブラウザ・シークレットウィンドウでは共有されません。

### 主な保存キー

- `demo_crud_drivers_v1`
- `demo_crud_pickups_v1`
- `demo_crud_destinations_v1`
- `demo_crud_stops_v1`
- `demo_crud_assignments_v1`
- `demo_crud_logs_v1`

## 確認手順

### 1. 初期表示

1. `index.html` を開く
2. 画面上部の表示基準日を確認
3. 必要に応じて「サンプル生成」を押す

### 2. STOP入力から反映確認

1. 「STOP入力」タブを開く
2. 引取日・納入日・集荷先・送付先・時刻・数量・重量を入力
3. 「保存」を押す
4. 「STOP一覧・CRUD」タブに入力データが表示されることを確認
5. 「ダッシュボード」タブのSTOP件数が増えることを確認
6. 「配車割当」タブで対象STOPが選択できることを確認
7. 「営業所サマリー」タブに数量・重量が反映されることを確認

### 3. CRUD確認

「STOP一覧・CRUD」タブで以下を確認します。

- 編集：入力タブへ値が読み込まれ、更新後に一覧へ反映される
- 複製：同じ内容のSTOPが新しいIDで追加される
- 削除：STOPと紐づく割当が削除される

### 4. 割当確認

1. 「配車割当」タブを開く
2. STOPを選択
3. ドライバー・roleを選択して「追加」
4. 現割当に表示されることを確認
5. 完了・保留・未完了・削除を操作できることを確認

## 注意点

この実装は一時保存のデモ版です。
本番運用で複数人共有する場合は、Supabaseや社内DBなどに保存先を切り替える必要があります。
